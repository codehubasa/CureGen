Brain Tumor Detection AI

A powerful Flask-based web application that detects brain tumors from MRI and CT scan images using deep learning models. This system provides fast, accurate predictions along with detailed reports, making it useful for educational, research, and prototype medical applications.

🚀 Features

🧠 MRI & CT Scan Support

Analyze both MRI and CT scan images seamlessly

⚡ Real-Time Predictions

Fast inference using pre-trained TensorFlow models

📊 Detailed Results

Displays:
Predicted tumor type
Confidence score
Class probabilities

📄 PDF Report Generation
Download complete analysis results as a PDF

🖱️ Drag & Drop Upload
Simple and user-friendly image upload interface

📈 Progress Visualization
Real-time processing indicator for better UX

🧬 Supported Tumor Types
Glioma
Meningioma
Pituitary
No Tumor

🛠️ Tech Stack

Backend: Flask (Python)

AI Models: TensorFlow / Keras

Frontend: HTML, CSS, JavaScript

Other Tools: PDF generation libraries

📋 Prerequisites

Make sure you have:
Python 3.8+
pip (Python package manager)

🧪 How to Use
Select scan type (MRI or CT)

Upload an image

Click "Start AI Processing"

View prediction results

Download PDF report

⚠️ Error Handling

The system handles:
Invalid or missing image uploads
Unsupported file formats
File size limits (max: 16MB)
Model loading issues
Prediction failures
